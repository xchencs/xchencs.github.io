Xiang Chen · Nantong University

My research sits at the intersection of artificial intelligence and software engineering: around software vulnerabilities, software testing and code language models, I study how programs fail, how they are tested, and how they can be repaired automatically.

Research Interests

Vulnerabilities
Detection, assessment, type prediction and automated repair
Code LLMs
LLM4SE, code generation and the security of code models (backdoors, poisoning, defences)
Program generation
Generating, repairing and automatically judging solutions for algorithmic problems
Defect prediction
Change representation, just-in-time defect and vulnerability prediction, commit messages
Software testing
Test case generation, regression testing, combinatorial and mutation testing
Repository mining
Stack Overflow mining, code summarisation, code and API search

Prospective Students & Collaboration

I admit 1–2 master's students every year in intelligent science and technology, computer technology, and artificial intelligence. Topics span large language models, deep learning, natural language processing and software engineering. Motivated undergraduates are also welcome to join the group for algorithm contests, innovation competitions, or research on LLM-based software engineering.

I am looking for students who are self-driven, quick to learn, and comfortable with programming.

Email: xchencs@ntu.edu.cn. Student awards and destinations are listed on their own pages.

I am also happy to collaborate on software engineering (TSE, TOSEM, ICSE, FSE, ISSTA, ASE), security (TDSC, TIFS, CCS, S&P, USENIX Security, NDSS) and HCI (CHI, UIST) topics.
