陈翔 · 南通大学 人工智能与计算机学院

我的研究位于人工智能与软件工程的交叉处：围绕软件漏洞、软件测试与代码大模型，研究程序缺陷的理解、检测与自动修复。

研究兴趣

软件漏洞
漏洞的检测、评估、类型预测与自动修复
代码大模型
LLM4SE、代码生成与代码模型安全（后门、投毒与防御）
竞赛程序生成
面向算法题目的程序生成、修复与自动评测
缺陷预测
代码变更表示、即时缺陷与漏洞预测、提交信息生成
软件测试
测试用例生成、回归测试、组合测试与变异测试
仓库挖掘
Stack Overflow 挖掘、代码摘要、代码与 API 搜索

招生与合作

每年招收智能科学与技术（学硕）、计算机技术（专硕）、人工智能（专硕）硕士生 1–2 人，方向涉及大语言模型、深度学习、自然语言处理与软件工程。也欢迎学有余力的本科生加入课题组，参与算法竞赛、创新创业竞赛和基于大语言模型的软件工程研究。
